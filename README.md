# 🏥 AI-Powered Radiology Report Audit & Quality Analyzer

A production-ready AI-powered quality assurance web application for radiology reports — built with React, Vite, Tailwind CSS, and Python (Flask). Supports both **Groq (Llama 3.3 70B)** and **Google Gemini AI**.

> ⚠️ **Disclaimer:** This tool is for quality assurance and educational purposes only. It does not generate diagnoses or clinical advice. All suggestions must be reviewed by a qualified radiologist.

---

## 📁 Project Structure

```
radiology-report-audit-app/
├── src/                        # React Frontend (Components, Pages, Modals)
├── css/ & js/                  # Legacy styling & core JS assets
├── sample_reports/             # Sample radiology report files for testing
├── utils/                      # Text extractors (PDF, DOCX) & PDF exporter
├── dist/                       # Production web build (generated by vite)
├── .github/workflows/deploy.yml # Automated GitHub Pages workflow
├── server.py                   # Flask REST API server & static host
├── config.py                   # System configuration & API key management
├── render.yaml                 # 1-Click Render deployment configuration
├── requirements.txt            # Python dependencies
├── Procfile & runtime.txt      # Gunicorn & Python runtime configuration
└── package.json & vite.config  # Node.js dependencies & Vite configuration
```

## 💻 Local Development

### 1. Backend (Flask)
```bash
python -m venv .venv
source .venv/bin/activate  # On Windows: .venv\Scripts\activate
pip install -r requirements.txt
python server.py
```
> Server will start at `http://localhost:5000`

### 2. Frontend (Vite React)
```bash
npm install
npm run dev
```
> Dev client will start at `http://localhost:3000` with API proxy configured to localhost:5000.

## 🚀 Live Deployment Options

### Option A: Render (Full-Stack Deployment - Recommended)
1. Sign up on [Render.com](https://render.com) and create a **Web Service**.
2. Connect your GitHub repository (`radiology-report-audit-app`).
3. Render automatically reads `render.yaml` or use these settings:
   - **Build Command:** `npm install && npm run build && pip install -r requirements.txt`
   - **Start Command:** `gunicorn server:app`
4. Add Environment Variables in Render Dashboard:
   - `GROQ_API_KEY`: Your Groq API key
   - `GEMINI_API_KEY`: Your Gemini API key

### Option B: GitHub Pages (Static UI Deployment)
1. Go to your GitHub repository **Settings → Pages**.
2. Under **Build and deployment**, set **Source** to **GitHub Actions**.
3. The included workflow `.github/workflows/deploy.yml` will automatically build and publish the frontend to `https://YOUR-USERNAME.github.io/radiology-report-audit-app/`.

## 🔐 API Key Configuration

Keep API keys on the server, never exposed in client code. Copy `.env.example` to `.env` and set your key:

```env
GROQ_API_KEY=your_groq_key_here
# GEMINI_API_KEY=your_gemini_key_here
```
