# 🏥 AI-Powered Radiology Report Audit & Quality Analyzer

A production-ready AI-powered quality assurance web application for radiology reports — built with React, Vite, Tailwind CSS, and Python (Flask). Supports both **Groq (Llama 3.3 70B)** and **Google Gemini AI**.

> ⚠️ **Disclaimer:** This tool is for quality assurance and educational purposes only. It does not generate diagnoses or clinical advice. All suggestions must be reviewed by a qualified radiologist.

---

## 📁 Project Structure

```
radiology-report-audit-app/
├── src/                         # React Frontend (Components, Audit Dashboard, Analytics)

```

## 💻 Local Development

### 1. Backend (Flask)
```bash
python -m venv .venv
source .venv/bin/activate  # On Windows: .venv\Scripts\activate
pip install -r requirements.txt
python server.py
```
> Server will start at `http://localhost:5000`

### 2. Frontend (Vite React)
```bash
npm install
npm run dev
```
> Dev client will start at `http://localhost:3000` with API proxy configured to `http://localhost:5000`.

## 🌐 Deploying & Live Hosting

### Option A: GitHub Pages (Automatic Web Deployment via GitHub Actions)
1. Push code to your GitHub repository:
   ```bash
   git add .
   git commit -m "Deploy to GitHub Pages"
   git push origin main
   ```
2. Go to repository **Settings → Pages**.
3. Under **Build and deployment → Source**, select **GitHub Actions**.
4. The workflow in `.github/workflows/deploy.yml` will automatically build the Vite app and deploy it to:
   `https://debanshidas.github.io/radiology-report-audit-app/`

### Option B: Render (Full-Stack Deployment with Flask API)
1. Sign up on [Render.com](https://render.com) and create a **Web Service**.
2. Connect your GitHub repository (`debanshidas/radiology-report-audit-app`).
3. Render will read `render.yaml` automatically:
   - **Build Command:** `npm install && npm run build && pip install -r requirements.txt`
   - **Start Command:** `gunicorn server:app`
4. Add Environment Variables in Render Dashboard:
   - `GROQ_API_KEY`: Your Groq API key
   - `GEMINI_API_KEY`: Your Gemini API key

## 🔐 API Key Configuration

Keep API keys secure. Copy `.env.example` to `.env` and set your key:

```env
GROQ_API_KEY=your_groq_key_here
# GEMINI_API_KEY=your_gemini_key_here
```

The `.env` file is ignored by Git. For production deployments (e.g. Render), set environment variables directly in the host's dashboard.
